AntennaPod 2-Way Sync Setup

AntennaPodder supports both the standard gPodder protocol and the Nextcloud gPodder Sync protocol. You can configure AntennaPod with either provider.

Option A: Using "Nextcloud" provider in AntennaPod

  1. In AntennaPod, go to Settings > Synchronization > Provider > Select Nextcloud.
  2. Enter your server URL:
http://<your-server-ip>:3000
AntennaPod will automatically connect to the compatibility endpoints and sync subscriptions and playback positions seamlessly.

Option B: Using "gpodder.net" provider in AntennaPod

  1. In AntennaPod, go to Settings > Synchronization > Provider > Select gpodder.net.
  2. Tap Server URL (or custom server) and enter:
http://<your-server-ip>:3000
Use your AntennaPodder username and password.
